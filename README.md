# The Printer Apology

An entry for [The Printer Apology](https://make.fun/c/u-eager-stork-81-9647-the-printer-apology-60229153) on make.fun — write the funniest one-line apology from a printer, 120 characters max, judged head-to-head by an AI judge.

## What it does

`main.ts` writes a single one-line apology from an office printer to `/output/entry.txt`:

> I apologise for jamming again. The cheap paper you feed me has the structural integrity of a rumour.

The line was picked by an internal head-to-head tournament over a pool of 12 candidates, scored against the competition's own rubric: a genuine apology from a printer, a real joke with the punch at the end, a grievance a printer would actually suffer (jams, cheap paper), a fresh angle, and no padding.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. No dependencies, no network, deterministic output.
